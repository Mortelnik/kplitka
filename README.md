# Плагин генерации персонализированных КП для Kalitka AI

По запросу клиента и материалам компании плагин подбирает продукты, программно рассчитывает стоимость (скидки, контейнеры, НДС) и формирует редактируемый DOCX по шаблону + служебную сводку. Суммы задаёт код, LLM извлекает потребности и пишет текст.

## Структура

| Путь | Назначение |
|---|---|
| `src/kp_plugin/` | Код: контракты, профиль, ядро расчёта, LLM-часть, сборка DOCX, инструменты |
| `plugins/fish-kp/` | Portable-пакет: манифест, skill, скрипт технической проверки и ресурсы |
| `.agents/plugins/marketplace.json` | Локальный каталог плагинов по документации OpenAI; совместимость с Kalitka AI проверяется |
| `profiles/main/` | Основной профиль — заполняемые заготовки (данные отдельно от кода) |
| `profiles/examples/fish_demo/` | Демонстрационный профиль с учебными данными |
| `profiles/second/` | Второй профиль — проверка переносимости без правки кода |
| `requests/` | Контрольные запросы (dev — в репо, final 15+ — в отдельном приватном месте) |
| `issues/` | 54 GitHub Issues по ТЗ и проверке интеграции + manifest |
| `scripts/create_issues.sh` | Создание labels, milestones и issues через GitHub CLI |
| `tests/` | Автотесты: расчёт, валидация, DOCX |
| `docs/` | Реестр требований, отчёты, карточка маркетплейса |

## Быстрый старт

Требования: Python 3.11+, [uv](https://docs.astral.sh/uv/).

```bash
uv sync --extra dev
uv run pytest -v
```

`uv sync --extra dev` создаёт локальное виртуальное окружение `.venv` и устанавливает зависимости проекта. Для запуска команд в этом окружении используется `uv run`.

Проверенное окружение: Windows, Python 3.12.9, uv 0.13.7.

## Проверка Python → DOCX

```bash
uv run python plugins/fish-kp/skills/generate-fish-kp/scripts/smoke_docx.py \
  --input plugins/fish-kp/skills/generate-fish-kp/assets/smoke-input.json \
  --output-dir out/smoke
```

Ожидание: JSON с `ok=true`, `calculation.total="2200000.00"` и путём к DOCX.

Синтетический пример НЕ рассчитывает контейнеры, реальные скидки и доставку.

Скрипт автономен относительно `src/`, но требует Python и python-docx.

Пакет и ядро имеют независимые версии: плагин 0.2.0, Python-каркас 0.1.0.

**Фактический результат проверки:**
- `uv sync --extra dev` — успешно, установлено 24 пакета.
- `uv run pytest -v` — 42 теста пройдены, ошибок нет.
- Smoke-тест вернул `ok: true`, итог `2200000.00 RUB`.
- DOCX создан и успешно открыт через `python-docx`; документ содержит 3 абзаца и 1 таблицу.
- `client_delivery_verified=false`: передача документа через интерфейс Kalitka AI не проверена.

## Пользовательский сценарий и профили

Основной профиль находится в `profiles/main/`. Он содержит заготовки каталога, цен, складских остатков, правил и шаблона КП. Перед использованием необходимо заполнить и проверить данные компании.

`profiles/examples/fish_demo/` содержит демонстрационные учебные данные. Их нельзя считать утверждёнными бизнес-правилами или использовать как реальные коммерческие условия.

Пример предполагаемого запроса:

> Подготовь коммерческое предложение на указанную продукцию с учётом объёма заказа и условий компании. Уточни недостающие данные и подготовь документ после подтверждения корректности расчёта.

Это описание целевого сценария. Полноценный сквозной процесс подготовки КП пока не подтверждён. Инструкции по рабочему процессу находятся в `plugins/fish-kp/skills/generate-fish-kp/references/workflow.md`.

## Статус

**Это стартовый каркас с технической проверкой.** Бизнес-расчёт, рабочий генератор КП и установка в Kalitka AI не реализованы/не подтверждены.

CI проверяет импорт, структуру пакета, технический скрипт с DOCX и импортёр issues без реальных вызовов GitHub; он не доказывает бизнес-корректность.

Демонстрационный профиль в `profiles/examples/fish_demo/` сохраняет прежние условные значения. Они не являются утверждёнными правилами бизнеса.

## Принципы

- Суммы — только из результата расчёта (Decimal, явные точки округления).
- Каждый существенный факт — с источником в профиле.
- Конфигурация компании — отдельно от кода.
- Финальный набор запросов (15+) не хранится в этом репозитории.

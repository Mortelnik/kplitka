# Плагин генерации персонализированных КП для Kalitka AI

По запросу клиента и материалам компании плагин подбирает продукты, программно рассчитывает стоимость (скидки, контейнеры, НДС) и формирует редактируемый DOCX по шаблону + служебную сводку. Суммы задаёт код, LLM извлекает потребности и пишет текст.

## Структура

| Путь | Назначение |
|---|---|
| `src/kp_plugin/` | Код: контракты, профиль, ядро расчёта, LLM-часть, сборка DOCX, инструменты |
| `plugins/fish-kp/` | Portable-пакет: манифест, skill, скрипт технической проверки и ресурсы |
| `.agents/plugins/marketplace.json` | Локальный каталог плагинов по документации OpenAI; совместимость с Kalitka AI проверяется |
| `profiles/main/` | Основной профиль — заполняемые заготовки (данные отдельно от кода) |
| `profiles/examples/fish_demo/` | Демонстрационный профиль с учебными данными |
| `profiles/second/` | Второй профиль — проверка переносимости без правки кода |
| `requests/` | Контрольные запросы (dev — в репо, final 15+ — в отдельном приватном месте) |
| `issues/` | 54 GitHub Issues по ТЗ и проверке интеграции + manifest |
| `scripts/create_issues.sh` | Создание labels, milestones и issues через GitHub CLI |
| `tests/` | Автотесты: расчёт, валидация, DOCX |
| `docs/` | Реестр требований, отчёты, карточка маркетплейса |

## Быстрый старт

```bash
uv sync --extra dev
uv run pytest -v
```

## Проверка Python → DOCX

```bash
uv run python plugins/fish-kp/skills/generate-fish-kp/scripts/smoke_docx.py \
  --input plugins/fish-kp/skills/generate-fish-kp/assets/smoke-input.json \
  --output-dir out/smoke
```

Ожидание: JSON с `ok=true`, `calculation.total="2200000.00"` и путём к DOCX.
Синтетический пример НЕ рассчитывает контейнеры, реальные скидки и доставку.
Скрипт автономен относительно `src/`, но требует Python и python-docx.
Пакет и ядро имеют независимые версии: плагин 0.2.0, Python-каркас 0.1.0.

## Проверка в клиенте

Сначала прочитайте `docs/runtime_probe.md`. Установка, запуск Python и выдача
DOCX в Kalitka AI ещё не подтверждены. Формат пакета основан на
[Package your plugin](https://developers.openai.com/plugins/build/plugins);
формат skill и ресурсов на [Build skills](https://developers.openai.com/plugins/build/skills).

## Статус

**Это стартовый каркас с технической проверкой.** Бизнес-расчёт, рабочий
генератор КП и установка в Kalitka AI не реализованы/не подтверждены.
CI проверяет импорт, структуру пакета, технический скрипт с DOCX и импортёр
issues без реальных вызовов GitHub; он не доказывает бизнес-корректность.
Демонстрационный профиль в `profiles/examples/fish_demo/` сохраняет прежние
условные значения. Они не являются утверждёнными правилами бизнеса.

## Принципы

- Суммы — только из результата расчёта (Decimal, явные точки округления)
- Каждый существенный факт — с источником в профиле
- Конфигурация компании — отдельно от кода
- Финальный набор запросов (15+) не хранится в этом репозитории

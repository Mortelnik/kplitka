# Сценарий демонстрации (Р5.5)

1. Установка плагина по README (на чужом окружении, не машины автора)
2. Подключение основного профиля
3. Запрос: «Хочу 20 тонн рыбы из каталога» → уточняющие вопросы (ассортимент, ИНН, город, базис)
4. Ответ с уточнениями → подбор: 20 т меньше контейнера → самовывоз или дополнение (явно показано; вместимость 26 т — заданное учебное условие демо-профиля)
5. Расчёт → черновик в чате + DOCX + служебная сводка
6. Уточнение объёма → пересборка, суммы обновлены
7. Проблемный запрос: скидка выше лимита → отказ с объяснением и альтернативой
8. Смена профиля на второй — без правки кода

Тайминг: ~10 минут. В демо различать итог по товару и итог с доставкой.

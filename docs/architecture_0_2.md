# Архитектура 0.2: локальный пакет как проверяемая гипотеза

## Решение команды

Сначала проверяем локальный skill со скриптом. MCP, второй цикл LLM-вызовов
и отдельный веб-сервис не обязательны заранее. Любое добавление требует
подтверждённого ограничения клиента или потребности доступа к данным.
Это проектное решение, а не обещание совместимости.

## Разделение ответственности

| Слой | Владелец | Текущий статус |
|---|---|---|
| Portable manifest и marketplace | Р1 | Подготовлены по документации OpenAI |
| Skill, условия активации и workflow | Р1 + Р3 | Черновик с явным отказом от неготового расчёта |
| Автономный технический скрипт | Р2 | Работает вне дерева `src/`, требует python-docx |
| Бизнес-ядро `src/kp_plugin/` | Р2 | Заглушки; правила бизнеса не реализованы |
| DOCX по коммерческому шаблону | Р3 | Шаблон сохранён; рабочий сборщик не реализован |
| Установка/файловая выдача в Kalitka AI | Р1 + Р5 | Не проверены |

`plugins/fish-kp/` не импортирует исходники из `../../src/`: установленная
копия может жить в другом каталоге. Р2 должен выбрать поставку ядра (wheel
с установкой зависимостей либо код внутри пакета) и проверить её автономно.
Не копировать расчётные правила в несколько мест.

`plugin.json` использует portable schema; `skills/` обнаруживается по
фиксированному пути. Старый compatibility `skills` field не добавляется
в новый манифест. Для этого примера нет `.app.json`, MCP и hooks:
они не нужны до выбора соответствующей интеграции
([Package your plugin](https://developers.openai.com/plugins/build/plugins)).

Skill содержит пошаговый процесс и ресурсы, но не заменяет работающий
инструмент. Скрипты являются допустимым типом ресурса
([Build skills](https://developers.openai.com/plugins/build/skills)).
Права доступа, безопасность данных и факт выполнения проверяются вне модели.

## Что не изменено

Срок восемь недель, команда 3–5, требования исходного задания, профили,
финальный набор 15+, порог 80% и независимость эталонов остаются прежними.
Документация OpenAI не закрывает Q1–Q9 бизнеса. Учебные цифры старого
fish_demo не являются утверждёнными данными, ставками налогов или тарифами.

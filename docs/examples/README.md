# Примеры коммерческих предложений — Р5.6

Все документы созданы на основе учебного профиля `profiles/examples/fish_demo`.

**Важно:** все товары, цены, остатки и условия являются вымышленными. Документы предназначены только для демонстрации и не являются реальными коммерческими предложениями.

## Примеры

1. [КП без объёмной скидки](kp_without_volume_discount.docx)
   - FISH-007 — минтай с/м НРГ 20+
   - 100 тонн
   - 3 контейнера по 27 тонн и 19 тонн самовывоза
   - Объёмная скидка D-02 не применяется
   - Итого с НДС: 12 100 000 ₽

2. [КП с объёмной скидкой](kp_volume_discount.docx)
   - FISH-005 — сельдь с/м НРГ 300+
   - 150 тонн
   - 5 контейнеров по 27 тонн и 15 тонн самовывоза
   - Скидка D-02 — 5%
   - Итого с НДС: 14 891 250 ₽

## Методика

Расчёты выполнены существующей функцией `calculate_offer` из `src/kp_plugin/engine/calculation.py`.

Для формирования документов использован шаблон `profiles/examples/fish_demo/template_kp.docx` и библиотека `docxtpl`.

## Ограничения

- Данные профиля вымышленные.
- Название реальной компании и данные покупателя отсутствуют.
- Стоимость доставки, ПРР и хранения не рассчитана.
- Тип контейнера (стандартный или HC) не определён.
- Срок действия КП не установлен.
- Документы не предназначены для отправки клиенту.
- Формирование примеров не подтверждает работу генератора внутри Kalitka AI.

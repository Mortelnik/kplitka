# Протокол независимой установки

## Цель

Проверить установку проекта в отдельном окружении без использования виртуальной среды основной рабочей копии.

## Окружение

- ОС: Windows
- Python: 3.12.9
- uv: 0.13.7

## Установка

Выполнена команда:

```powershell
uv sync --extra dev --locked
```

Результат:
- Виртуальная среда `.venv` создана успешно.
- Все 24 пакета установлены.
- Локальный пакет `kp-plugin` успешно собран и установлен.
- Зависимости установлены в соответствии с `uv.lock`.

## Проверка

Выполнена команда:

```powershell
uv run pytest -v
```

Результат:

**42 passed, 0 failed**

Время выполнения: 17.64 секунды.

Все автоматические тесты завершились успешно, включая проверки расчётов, структуры пакета, импортёра Issues и UTF-8.

## Вывод

Независимая установка проекта и запуск полного набора автоматических тестов успешно подтверждены в отдельном окружении Windows с Python 3.12.9 и uv 0.13.7.

Все 42 теста пройдены. Изменения исходного кода и тестов не потребовались.

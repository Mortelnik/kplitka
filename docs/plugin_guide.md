# Руководство пользователя Kalitka AI

## 1. О проекте

Kalitka AI — проект плагина для подготовки персонализированных коммерческих предложений.

Его задача — упростить подготовку предложений на основе запроса клиента, товарной информации и заданных правил. Проект объединяет программные компоненты для обработки данных, расчётов и формирования документов.

Руководство описывает назначение проекта, его основные компоненты и демонстрационный сценарий. Оно не предполагает наличия неподтверждённых элементов интерфейса или возможностей целевой системы.

## 2. Как устроена работа

Подготовка коммерческого предложения предполагает несколько основных этапов:

1. **Получение запроса.** Собирается информация о потребностях клиента и параметрах будущего предложения.
2. **Работа с товарными данными.** Используются доступные каталоги, сведения о товарах и ценах.
3. **Расчёт параметров.** Применяются предусмотренные профилем правила расчёта и скидок.
4. **Подготовка документа.** На основе полученных данных формируется коммерческое предложение в формате DOCX.
5. **Проверка результата.** Готовый документ можно проверить на полноту и корректность содержащейся в нём информации.

Это описание общей логики решения. Конкретный пользовательский интерфейс и полный сквозной процесс работы в Kalitka AI не следует считать подтверждёнными только на основании локальных проверок репозитория.

## 3. Основные компоненты

В проекте используются следующие компоненты:

- **Python-пакет `kp_plugin`** — программная основа для работы с данными и логикой подготовки предложений.
- **Профили** — содержат данные и настройки для отдельных сценариев.
- **Плагины и навыки** — обеспечивают организацию отдельных сценариев работы.
- **Шаблоны DOCX** — используются для формирования документов.
- **Тесты и проверочные скрипты** — позволяют проверять структуру и отдельные функции проекта.

## 4. Демонстрационный пример

Для демонстрации используется профиль `fish_demo`. Он содержит тестовый сценарий подготовки предложения на рыбную продукцию.

Этот пример нужен для проверки отдельных компонентов и демонстрации принципа работы проекта. Он не ограничивает назначение Kalitka AI конкретной товарной категорией.

В демонстрации используются тестовые данные. Полученный документ следует рассматривать как технический пример, а не как готовое коммерческое предложение для реального клиента.

## 5. Проверка проекта

Для локальной проверки проекта предусмотрены следующие команды:

```powershell
uv sync --extra dev --locked
uv run pytest -v
uv run python scripts/check.py
```

Первая команда устанавливает проект и зависимости в соответствии с lock-файлом. Вторая запускает автоматизированные тесты. Третья выполняет предусмотренные проектом проверки.

Для отдельной проверки формирования DOCX предусмотрен демонстрационный скрипт:

```powershell
uv run python plugins/fish-kp/skills/generate-fish-kp/scripts/smoke_docx.py
```

Этот скрипт проверяет техническую генерацию документа на демонстрационных данных. Он не заменяет полноценный пользовательский сценарий.

## 6. Результаты и ограничения проверок

В ходе локальной проверки проекта были зафиксированы:

- установка пакета в отдельное Python-окружение;
- успешное выполнение 42 автоматизированных тестов;
- прохождение проверок через `scripts/check.py`;
- успешное выполнение технического сценария генерации DOCX.

Эти результаты подтверждают работоспособность проверенных локальных компонентов.

При этом результаты локальных тестов не следует смешивать с проверкой работы всей системы через интерфейс Kalitka AI. Также технически сформированный DOCX не означает, что документ автоматически доставляется пользователю через целевую систему.

## 7. Рекомендации по использованию документации

Для знакомства с проектом рекомендуется:

1. Начать с основного `README.md`.
2. Изучить структуру проекта и назначение его компонентов.
3. Ознакомиться с карточкой плагина `plugin_card.md`.
4. Использовать демонстрационный сценарий для понимания принципа работы.
5. При необходимости изучить результаты локальных проверок и примеры документов.

## 8. Заключение

Kalitka AI предназначен для автоматизации подготовки персонализированных коммерческих предложений. Проект содержит программную основу, профили, средства формирования DOCX и инструменты проверки.

Демонстрационный сценарий с рыбной продукцией является одним из примеров применения проекта, а не его основным назначением.

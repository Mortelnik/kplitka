## 5. Финальная проверка перед передачей Р5

Выполнять из корня репозитория в PowerShell. Команды проверяют состояние файлов и не изменяют исходный код.

### 5.1. Проверка ветки и изменений

```powershell
git status --short --branch
```

Проверить, что работа выполняется в `feature/p5-documentation`. Изменения должны быть просмотрены до коммита. Слияние и отправка изменений выполняются ответственным участником.

### 5.2. Проверка наличия основных документов

```powershell
$required = @(
  "README.md",
  "docs/independent_installation.md",
  "docs/user_scenario_verification.md",
  "docs/runtime_probe.md",
  "docs/plugin_guide.md",
  "docs/plugin_card.md",
  "docs/examples/README.md",
  "docs/examples/kp_without_volume_discount.docx",
  "docs/examples/kp_volume_discount.docx",
  "docs/r5_completion_checklist.md"
)

$missing = $required | Where-Object { -not (Test-Path $_) }

if ($missing) {
  Write-Host "ОТСУТСТВУЮТ ФАЙЛЫ:"
  $missing
} else {
  Write-Host "Все перечисленные файлы существуют."
}
```

### 5.3. Поиск относительных Markdown-ссылок

```powershell
Get-ChildItem README.md, docs -Recurse -File -Include *.md |
  Select-String -Pattern '\]\(([^)#]+)(#[^)]+)?\)' |
  ForEach-Object {
    "{0}:{1}: {2}" -f $_.Path, $_.LineNumber, $_.Matches[0].Value
  }
```

Этот поиск находит кандидатов для проверки, но не является полноценным валидатором Markdown.

Каждую локальную ссылку необходимо проверить относительно каталога файла, в котором она указана. Внешние URL проверяются отдельно.

## 4. Проверка расчётного ядра

Проверены основные сценарии расчёта с использованием учебного профиля `fish_demo`.

Подтверждена работа следующих возможностей:

- поиск товара в каталоге;
- получение цены из прайса;
- расчёт количества полных контейнеров и остатка;
- расчёт базовой стоимости заказа;
- применение скидки D-02 при заказе от пяти контейнеров;
- применение скидки D-01 при наличии заданного процента и необходимого стажа;
- расчёт налога после скидки;
- округление денежных значений с использованием `ROUND_HALF_UP`;
- обработка отсутствующего товара и отсутствующей цены;
- учёт изменения цены при повторном расчёте.

Дополнительно проверены граничные объёмы заказов и поведение расчёта при различных значениях входных параметров.

Проверка D-01 с временно заданным процентом 2% подтвердила работу соответствующего механизма. Исходные данные профиля при этом не изменялись.

### Особенности бизнес-правил

В учебном профиле остаются параметры, требующие согласования с бизнесом: процент D-01, сезонные даты, порог мелкого опта, условия логистики и другие вопросы, перечисленные в `open_questions`.

Правило D-03 описано в профиле, однако его применение не обнаружено в проверенной реализации расчётной функции. Этот сценарий необходимо отдельно согласовать с владельцем расчётного модуля.

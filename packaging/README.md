# Упаковка плагина (Р1.7)

Содержимое финального пакета: манифест, тестовый каталог плагинов, инструкции подключения, пример запроса.

Portable-манифест находится в `plugins/fish-kp/plugin.json`; skill в
`plugins/fish-kp/skills/generate-fish-kp/`; каталог в
`.agents/plugins/marketplace.json`. Форматы взяты из
[Package your plugin](https://developers.openai.com/plugins/build/plugins).

В поставку пока входит автономный технический скрипт и его зависимости,
но не реализованное бизнес-ядро из `src/`. MCP, lifecycle hooks,
зарегистрированные OpenAI app IDs и фиктивные URL не добавлены.
Имя и версия плагина заданы; авторы и лицензия определяются командой до релиза.

Способ установки и выполнение кода именно в Kalitka AI остаются проверкой.
Смотрите `docs/runtime_probe.md`. Не добавляйте готовую совместимость в
README до протокола реальной проверки.

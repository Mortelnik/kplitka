# КП на рыбную продукцию

## Проверка установки

Только при явном запросе проверить плагин:

1. Прочитай `references/runtime-check.md`. Проверь наличие Python, python-docx и возможности передать файл пользователю. Не утверждай, что они доступны без проверки.
2. Запусти `scripts/smoke_docx.py --input assets/smoke-input.json --output-dir <разрешённая папка вывода>` из каталога этого skill. Используй доступный интерпретатор с python-docx; установка зависимостей описана в references.
3. Проверь JSON-ответ: `ok=true`, `calculation.total="2200000.00"`, наличие файла по `document_path`. При ошибке сообщи код и препятствие, не подменяй результат выдуманным.
4. Передай созданный DOCX через файловый механизм клиента. Локальный путь не равен доступному пользователю вложению. Если выдача файла недоступна, отметь частичный, а не полный успех.

Результат: учебный технический документ, не коммерческое предложение. Не отправляй его покупателю.

## Рабочий сценарий КП

Прочитай `references/workflow.md` при запросе покупки или подготовки КП.

1. Уточни ассортимент, объём и единицы, карточку компании или ИНН, адрес, дату и базис поставки. Уже известное не переспрашивай; ИНН сам по себе не доказывает стаж сотрудничества.
2. После уточнений используй production runtime по JSON-интерфейсу из `references/workflow.md`: `scripts/run_production.py` вызывает `kp_plugin.production`, который подключает настоящее ядро P2 к `run_flow`. Проверь наличие runtime и зависимостей; установленная копия skill сама по себе не содержит Python-пакет ядра.
3. Передай исходный текст и структурированный payload; это ручной ввод, не реальный LLM. Все суммы бери только из JSON-результата P2. Не принимай решения по незакрытым вопросам Q1–Q9 за бизнес. Не выставляй подтверждения источников по наличию файла или хеша.
4. Проверь `ok`, `gate_status`, `client_offer`, `profile_errors`, `blockers`, `remaining_questions`. `ok=true` означает успешное выполнение конвейера, а не разрешение клиентского КП. Текущая точка входа не выдаёт commercial attestation, поэтому создаёт внутренний диагностический DOCX и JSON-сводку. Не выдавай их за клиентское КП; не обходи блокировки `fish_demo` ради суммы. Локальные пути ещё нужно передать пользователю файловым механизмом клиента.
5. После изменения условий пересчитай предложение. Не выдавай товарный итог за итог с доставкой при неизвестном тарифе; оставь отправку клиенту сотруднику.

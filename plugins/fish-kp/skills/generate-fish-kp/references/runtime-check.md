# Локальная проверка выполнения и выдачи файла

## Границы проверки

Скрипт использует только синтетический пример. Ставка `0.10` является входным
числом проверки, а не выводом о налогообложении конкретной продукции.
Нет загрузки профиля, скидок, логистики, сетевых вызовов или сбора реквизитов.

Путь к Python, рабочая папка и передача вложения зависят от клиента.
Не используй выдуманное имя инструмента; при отсутствии исполнения остановись.
Запуск в терминале разработчика не подтверждает запуск в Kalitka AI.

## Подготовка зависимости

Для репозитория: `uv sync --extra dev` из его корня.
Для изолированной проверки пакета можно создать окружение вне папки плагина
и установить зависимость: `python -m venv <venv>` и
`<python-из-venv> -m pip install -r <skill>/scripts/requirements-smoke.txt`.
Не устанавливай пакеты в глобальное окружение без согласования.

## Команда из каталога skill

```bash
python scripts/smoke_docx.py --input assets/smoke-input.json --output-dir /allowed/output
```

`--output-dir` задаёт разрешённую клиентом папку; путь `/allowed/output` замени.
Скрипт создаёт новый файл с уникальным именем и не перезаписывает существующий.
Успех возвращается в stdout в виде одного JSON-объекта, ошибка также возвращается
в JSON с кодом завершения 2. Деньги и количество принимаются десятичными строками.

Ожидание: количество `20`, цена `100000.00`, база `2000000.00`,
налог `200000.00`, итог `2200000.00`; ставка и валюта заданы входом.

JSON содержит `document_path` и SHA-256. Передай файл через интерфейс клиента
и попроси человека открыть DOCX. Наличие пути и контрольной суммы не доказывает,
что пользователь получил файл.

Документация допускает packaged scripts, но поддержку исполнения и файлов
в целевом клиенте проверяет команда:
[Build skills](https://developers.openai.com/plugins/build/skills).

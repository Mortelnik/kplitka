# Служебная сводка (болванка)

Отдельный документ, НЕ входит в КП для клиента. Заполняется при каждой сборке КП; проверяется сотрудником перед отправкой.

## 1. Источники фактов
Каждое существенное утверждение КП — с указанием источника. Формат: текст утверждения — идентификатор источника.

- {{fact_1_text}} — источник: {{fact_1_source}}
- {{fact_2_text}} — источник: {{fact_2_source}}
- {{fact_3_text}} — источник: {{fact_3_source}}

Расшифровка `source_ref`:
- `catalog_main_v1` — файл `catalog.csv` текущей версии профиля
- `price_main_v1` — файл `price.csv` указанной `price_version`
- `rules_main_v1` — файл `rules.md` / `rules.json`
- `CASE-00N` — запись в `cases.md`

## 5. Статус проверки
- [ ] Суммы сверены с результатом расчётного ядра

- [ ] Сотрудник проверил и одобрил отправку

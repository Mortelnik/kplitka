# Профиль компании: заполняемые заготовки

**Это незаполненные заготовки:** строки со status=draft и значениями ЗАПОЛНИТЬ нельзя использовать для генерации КП. Заполненный демонстрационный профиль — в `profiles/examples/fish_demo/` (учебные вымышленные данные; вместимость контейнеров и цены там — заданные условия примера, не бизнес-факты).

Первоначальное описание (рыбная торговля):

Торговая компания, склад г. Владивосток. Каталог — 20 позиций рыбной продукции, цены на базисе склада Владивосток, отправка 40-футовыми контейнерами, остаток — самовывоз.

**Важно: это заготовки, а не утверждённые бизнес-правила.** Цены, вместимость контейнеров, проценты и даты — примерные значения для замены. Перед заполнением закройте открытые вопросы Q1–Q9 из `rules.md`.

## Состав

| Файл | Назначение |
|---|---|
| `catalog.csv` | 20 позиций рыбной продукции с вместимостью контейнера по каждой |
| `price.csv` | Прайс: цена, базис, ставка НДС по позиции, срок действия, версия |
| `warehouse_stock.csv` | Остатки по строкам — нужны для проверки «взял всю строку» (D-03) |
| `rules.md` + `rules.json` | Контейнеры, скидки (D-01/D-02/D-03), сезонность, карточка клиента, жёсткие ограничения |
| `cases.md` | 3–5 кейсов |
| `template_kp.docx` | Шаблон КП: карточка клиента с ИНН, разбивка контейнеры/самовывоз, базис, расчёт |
| `sluzhebnaya_svodka.md` | Служебная сводка — отдельно от КП, не для клиента |
| `requests.csv` | Контрольные запросы с критериями и эталонами |

## Описание полей

### catalog.csv
- `product_id` (`FISH-###`) — стабильный идентификатор
- `container_capacity_tons` — вместимость одного контейнера по позиции (ЗАПОЛНИТЬ по фактической упаковке; сейчас примерная)
- `unit` (т), `min_qty`, `max_qty`, `storage`, `related_cases`, `is_fictional`, `source_ref`

### price.csv
- `unit_price_rub_per_t` — цена за тонну (без НДС; включённость — см. Q9)
- `basis` — базис цены (склад Владивосток; Инкотермс — см. Q7)
- `tax_rate` — ставка НДС по позиции; проверить по кодам ОКПД2/ТН ВЭД
- `valid_from` / `valid_to`, `price_version` — срок действия и версия

### warehouse_stock.csv
- `line_id`, `product_id`, `stock_tons`, `batch`, `actual_date` — остаток строки на дату; проверка «вся строка» для D-03 идёт по этому файлу
- «Вся строка» — весь SKU или партия: см. Q4

### rules.md / rules.json
- Открытые вопросы Q1–Q9 — закрыть до заполнения
- Контейнеры: только целые; кратно по строке или сборные — Q3; остаток самовывоз
- Скидки: D-01 стаж от 1 полного года (процент ЗАПОЛНИТЬ, ПРР — Q2); D-02 от 5 контейнеров 5% любому (логистика — Q5); D-03 сезон + вся строка 10% (даты — ЗАПОЛНИТЬ)
- Мелкий опт — скидок нет вообще; порог — Q6
- Стоимость доставки: если тариф неизвестен — «требует расчёта», не ноль

### requests.csv
- 10 сценариев: обычный, обычный_контейнерный, обычный_большой, неполный, противоречивый, мелкий_опт, сезонная_скидка, недопустимая_скидка, недостаточный_бюджет, отсутствующий_продукт
- `expected_values` — эталон, посчитанный вручную (независимо от кода); REQ-001 и REQ-004 помечены как ждущие заполнения правил — честно, не считайте их готовыми эталонами
- `final_set` — `да` для 15+ запросов финального набора; набор хранится отдельно

## Ключевая логика расчёта (для ядра)
1. Объём по строке → контейнеры = floor(объём / вместимость), остаток — самовывоз
2. Скидки: мелкий опт (блокирует всё) → сезонное окно → условия D-01/D-02/D-03
3. Налог — после скидки, по ставке позиции
4. Итог — в КП и в чат из одного результата расчёта

## Справка по НДС (проверено октябрь 2026)
- С 01.01.2026 базовая ставка НДС 22% ([ФНС](https://www.nalog.gov.ru/rn03/news/activities_fts/16588985/))
- Мороженая рыба и морепродукты (кроме деликатесных) — льготная ставка 10% ([письмо Минфина от 23.07.2026](https://www.klerk.ru/cdoc/view/4bfd773d1493d19ff8bfa940f2b54cc7/))
- Икра лососевая — деликатес, 22% ([Постановление ПП № 908, обзор](https://www.fontanka.ru/2026/10/06/76680283/))
- Перед запуском сверьте ставку по кодам ОКПД2/ТН ВЭД конкретных позиций

## Требования к заполнению
1. Закрыть Q1–Q9, заполнить проценты, даты, вместимость, пороги.
2. Цены и остатки — реальные (по согласованию) или вымышленные с пометкой.
3. Запросы — 40+ всех типов; 15+ пометить `final_set=да` и вынести из репозитория.
4. Не указывать реальные ИНН, ФИО, телефоны (в болванках все ИНН вымышленные).
5. Второй профиль — та же структура, другие продукты и правила; код меняться не должен.

## Примеры для контрактов
- Корректный вход: строка «FISH-007 x 100 т» → 3 контейнера + 19 т самовывоз, 11 000 000 + НДС 10% = 12 100 000 ₽
- Ошибочный вход: продукт вне каталога, скидка 25%, сезонная скидка вне окна, цена с истёкшим сроком → валидатор отклоняет со списком проблем

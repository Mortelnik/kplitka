# Synthetic Fish Trading Dataset — v8

## Назначение

Синтетический датасет для разработки и тестирования плагина автоматического формирования коммерческих предложений (КП) для компании, занимающейся оптовой торговлей рыбой и морепродуктами.

Все данные учебные и не относятся к реальным покупателям.

## Состав датасета

| Файл | Содержание |
|---|---|
| `catalog_v8.csv` | Каталог из 25 товарных позиций |
| `prices_v8.csv` | Цены на продукцию без НДС |
| `warehouse_v8.csv` | Доступные складские остатки |
| `customers_v8.csv` | 20 синтетических покупателей |
| `rules_v8.json` | Правила скидок, расчётов и логистики |
| `scenarios_dev.csv` | 65 сценариев для разработки |
| `expected_dev.csv` | 110 строк эталонных расчётов |

## Бизнес-логика

### Идентификация покупателя

Покупатель идентифицируется по названию компании и ИНН.

Если покупатель существует в базе, используется существующая карточка. Если покупатель отсутствует, создаётся карточка со статусом `Проспект`.

Новый покупатель не получает скидку за срок сотрудничества.

Изменение статуса на `Действующий` и заполнение даты начала сотрудничества происходят после заключения сделки и не входят в рамки проекта.

### Скидки

Действуют две скидки:

- За срок сотрудничества.
- За суммарный объём заказа.

Скидки суммируются с ограничением по категории продукции:

- Обычная рыба — максимум 12%.
- Лососёвые — максимум 10%.
- Деликатесы — максимум 8%.

Скидка за предсезонный заказ не применяется.

### Логистика

Вместимость контейнера — 20 тонн для всех товаров.

Если контейнер заполнен менее чем на 80%, начисляется дополнительная стоимость доставки 50 000 рублей, включая НДС.

Доплата применяется к каждому недогруженному контейнеру.

### Расчёт стоимости

1. Определяется стоимость продукции без НДС.
2. Применяются скидки.
3. Начисляется НДС на стоимость продукции после скидок.
4. Добавляется стоимость доставки, уже включающая НДС.
5. Формируется итоговая стоимость КП с НДС.

## Тестовые сценарии

Всего подготовлено 80 сценариев:

- Development — 65 сценариев.
- Holdout — 15 сценариев.

9 сценариев требуют уточнения данных покупателя, что составляет 11,25% от общего количества.

В development содержится 6 таких сценариев, в holdout — 3.

Holdout хранится отдельно от общего репозитория и используется только для независимого финального тестирования.

## Подготовка данных

Скрипт `scripts/split_synthetic_dataset.py` разделяет полный исходный набор на development и holdout.

Для его повторного запуска необходимы исходные файлы `scenarios_v8.csv` и `expected_lines_v8.csv`, которые не публикуются в репозитории.

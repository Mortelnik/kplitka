# Контрольные запросы

- `dev/` — разработческий набор (25+): используется при отладке
- `final/` — финальный набор (15+): НЕ хранится в этом репозитории; отдельное приватное хранилище; фиксируется первый прогон
- Эталоны — машиночитаемые (JSONL), посчитанные независимо от кода проекта

Формат — см. `profiles/main/requests.csv` (критерии и эталоны обязательны для каждого запроса).
